# 安全检查、信任边界与维护

## 本轮检查范围

本轮审读了自有插件、模型准备、HTTP 客户端/服务端、媒体解码、区间校验、缓存、生命周期及打包代码，并检查官方发行包中实际调用的模型定位、CNN、特征提取和 Viterbi 路径。模型、发行包及工具来源身份保存在本地验收目录。

这是一份限定范围的源代码与已知漏洞检查，不是“证明所有漏洞和模型后门都不存在”。第三方二进制、训练数据及模型训练过程没有在本项目中重建或形式化证明。

## 已实现并验证的边界

- **显式启用**：宿主只在管理员启用后导入客户端；没有自动安装脚本、隐藏定时器、遥测上传、在线训练或额外后台 Agent。
- **依赖隔离**：宿主不导入 TensorFlow；服务使用独立环境，代码不修改宿主环境、模型池、CUDA 配置或数据库。
- **认证**：独立随机 256-bit 服务令牌，常量时间比较；无默认秘密；初始化拒绝覆盖，标准输出不显示令牌。鉴权失败不触发推理。
- **网络**：默认只发布环回端口；没有 CORS；客户端拒绝重定向，不读取系统代理；HTTPS 启用证书验证。模型安装步骤可使用管理员配置的 HTTPS 代理，但仍验证固定哈希。
- **媒体**：调用端路径限制在授权根目录，拒绝符号链接媒体、目录外路径和非媒体后缀。FFmpeg 采用参数数组、限制协议/解复用器、移除来源元数据、超时和最大音频时长。
- **服务输入**：不接受 URL、文件路径或执行参数；只接受有界的标准 PCM WAV，拒绝重复长度头、Transfer-Encoding、非法 Content-Type 及超过上传总时限的请求。
- **服务输出**：固定模型身份；限制总响应及区间数；拒绝重复 JSON 键、NaN/Infinity、未知标签、重叠/缺口或音频时长不符。
- **缓存**：完整 WAV 字节哈希，不能只靠路径或 mtime；缓存有上限，仅保存分类结果，没有磁盘音频缓存。
- **评分**：只记录 shadow 分类，不虚构高光概率，不替换主分，不跳过 ASR，不根据音乐标签删除素材；失败由宿主原调度器明确回退。
- **模型供应链**：固定官方 wheel、版本与模型 SHA-256；推理阶段模型定位只允许已登记文件，拒绝运行时自动下载。上游模型资产没有独立发布签名，固定哈希不是发行者身份的数学证明。
- **容器**：非 root、根文件系统只读、删除 capabilities、no-new-privileges、固定镜像摘要及资源配额。正常服务的源码、依赖、模型及令牌只读，仅运行数据目录可写；安装写权限由单独的 setup 配置显式开启。
- **退出**：正常异常、Ctrl+C 和 SIGTERM 展开资源上下文并清理临时音频。硬杀/断电可能留下临时文件，管理员应保护目录并核对清理。

本轮回归覆盖了下载内容篡改与临时文件回收、精确长度读取、令牌不回显、认证/Origin、请求边界、慢请求体、非法结果、缓存失效及真实宿主生命周期。正常 Compose 的只读权限、健康状态和 Windows 到真实 CNN 服务的调用也做了单独验收。

## 已知依赖漏洞扫描

2026-10-16，使用 pip-audit 2.10.1 查询 PyPI 的已知漏洞数据库：

| 范围 | 实际查询 | 结果 |
| --- | --- | --- |
| Windows 开发环境 | 66 个第三方发行版 | 0 个已知漏洞发现 |
| Linux 实际推理环境 | 69 个实际安装发行版 | 0 个已知漏洞发现，且依赖一致性检查通过 |

开发清单另含本项目 editable 发行版，未在公共漏洞库中查询，项目代码单独审读和测试，没有把 editable 跳过当成源码安全证明。

容器在线扫描曾遇到 PyPI DNS 错误。因此从实际 Linux 环境导出无平台跳过的精确发行列表，在可联网 Windows 端查询同一数据库。安装时已经按锁文件哈希验证；扫描阶段 `--no-deps --disable-pip` 表示不重新安装或解析依赖，不关闭漏洞查询，不排除任何已安装的 Linux 包。

这些结果不是未来持续有效的保证。更新依赖后应重新同步锁文件、检查兼容性并复扫。宿主和基础操作系统的全部漏洞、驱动及固件不属于上述 Python 发行版数量；本项目没有自行维护系统库补丁。

## 使用者仍需保护的资源

宿主插件按照宿主现有信任模型拥有当前用户权限，不是安全沙箱。只安装审查过的插件。独立容器降低共享依赖和权限范围，但不能消除共享 CPU、内存、磁盘及 GPU 的竞争。

令牌会隐藏回显，但宿主插件数据库不是加密保险箱。`.local`、宿主数据库及备份必须由本机权限保护；Windows 上创建文件的 Unix mode 不等价于完整 Windows ACL。不要把真实令牌放进命令行、Git、PR 或截图。

本服务不对公网开放，也不设计为不受信任的多租户网关。直接 Linux 运行没有 Docker 的 CPU/内存配额；可使用 systemd/cgroup 等部署设施限制资源。客户端等待超时不能强行取消 TensorFlow 内部运算，若服务不可恢复应先保留诊断再正常重启。

本轮没有 CUDA 设备；GPU 模式未通过真实验收。模型对中文直播、唱歌和噪声的分类质量仍需代表性数据验证，错误分类属于业务风险，不能通过本轮性能一致性测试排除。

## 制品与本地数据

发行目标是轻量插件 ZIP、Python wheel 和源码包，真实 SHA-256、CRC32、大小和版本在 `dist/artifact-manifest.json`。插件 ZIP 不包含 TensorFlow、模型、令牌或运行缓存。

`.gitignore` 排除环境、`.local`、构建产物、缓存和真实 `.env`/令牌。用户稍后建立 Git 项目时应先检查待提交清单，不要手动强制加入这些目录。`.env.example` 只含非秘密的 Compose 参数。

敏感信息扫描覆盖自有交付源码、测试、配置和文档；本地含真实令牌的运行目录属于保密数据，不作为可发布源码提交或打包。
